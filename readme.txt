=== Landing Page Manager Pro ===
Requires at least: 5.9
Requires PHP: 7.4
Stable tag: 1.0.3
License: Proprietary

Premium analytics and conversion tracking for Landing Page Manager.

== Description ==

Landing Page Manager Pro adds page views, conversions, link clicks, engagement, heatmaps, and rage-click tracking to the Landing Page Manager plugin, which must be installed and active.

Updates are delivered through GitHub Releases of duppinstech/landing-page-manager-pro.
