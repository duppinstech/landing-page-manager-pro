# Code Style

- Follow WordPress PHP conventions and the patterns already used in this repository.
- Keep changes small and preserve existing public names and behavior unless the task requires a documented change.
- Use descriptive names, early returns where they clarify control flow, and comments only to explain non-obvious decisions.
- Keep supported PHP compatibility at 7.4 or later; do not introduce syntax or library requirements above the documented floor without approval.
- Keep documentation concise, use relative links within the repository, and update the changelog for user-visible behavior.
